## Summary

Center the 18px paper-plane glyph inside the conversation composer’s shared 2.25rem send action while preserving its filled accent treatment and accessible send contract.

Closes #4659

## Root cause

The icon-only send button combined the shared `composer-action-btn` geometry with the later legacy `send-btn` text-button rule. The later rule restored horizontal/vertical padding and text sizing inside the fixed square, while the shared icon baseline retained inline alignment. Those declarations competed with the grid centering contract and displaced the glyph.

## Changes

- Scope legacy send-button padding, font sizing, and flex alignment to send buttons that are not compact composer actions.
- Preserve the send button’s accent background, foreground colour, border, hover transition, and disabled treatment.
- Make icons directly inside compact composer actions block-level and neutralize their inline baseline offset.
- Add component and CSS-contract coverage for the accessible icon-only send button and its fixed zero-padding centering geometry.

## Anti-reinvention

The change reuses the existing `composer-action-btn`, `send-btn`, `Icon`, and `ChatPanelTests` seams. Current source and the related active-composer work were inspected; no new component, icon variant, layout container, or JavaScript positioning mechanism is introduced.
